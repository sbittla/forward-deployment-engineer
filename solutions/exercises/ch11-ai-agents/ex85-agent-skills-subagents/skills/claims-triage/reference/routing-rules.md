# Routing rules (owned by Claims Operations, reviewed quarterly)

| Condition | Queue | Severity |
|---|---|---|
| Injury, fatality, fire, suspected fraud | major-loss | 1 |
| Estimated loss above $50,000 | complex-property / complex-auto | 2 |
| Water damage, theft, collision with no injury | standard-home / standard-auto | 3 |
| Glass, roadside, documentation-only requests | fast-track | 4 |
