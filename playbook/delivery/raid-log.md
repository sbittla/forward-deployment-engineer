# RAID log (risk register)

| | |
|---|---|
| **Owner** | FDE; reviewed at every steering meeting |
| **When** | From week 1 to the close |
| **Inputs** | Everything that might go wrong, is assumed, has gone wrong or was decided |
| **Done when** | Every item has an owner; risks have probability, impact and mitigation; decisions have a rationale and a decider |
| **Book** | Chapter 2 · ex07 |

| Id | Type (R, A, I, D) | Description | Probability (1–5) | Impact (1–5) | Score | Mitigation or rationale | Owner | Due or confirm by | Status |
|---|---|---|---|---|---|---|---|---|---|

Escalation rules (agreed with the sponsor): any open risk scoring ≥ 15; any open issue more than 3 days overdue.
