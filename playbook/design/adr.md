# Architecture decision record

| | |
|---|---|
| **Owner** | The person proposing the decision; a named decider |
| **When** | Whenever a decision is expensive to reverse |
| **Inputs** | The options and the evidence for each |
| **Done when** | Accepted by a named decider; passes ex90's linter; has a revisit trigger |
| **Book** | Chapter 16 · ex90 |

# ADR-<n>: <decision in one line>
Status: proposed | accepted | superseded by ADR-<m>

## Context
What forces the decision, with numbers.

## Alternatives considered
- Option A: ...
- Option B: ...
(at least two)

## Decision
decided-by: <name and role>

## Consequences
Benefits, and at least one downside: cost, risk, trade-off, lock-in or complexity.

## Revisit when
The measurable conditions that should reopen this decision.
